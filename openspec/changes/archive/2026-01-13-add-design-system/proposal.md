# Change: 建立统一的设计系统 (Design System)

## Why
当前项目存在 UI 样式不统一的问题：
- 主题文件分散且重复（`app_colors.dart`, `app_color_palette.dart`, `app_theme.dart`）
- 颜色定义冲突（蓝色 #1976D2、#2196F3 和绿色 #4CAF50 混用）
- `app.dart` 使用 CupertinoApp，但定义了未使用的 Material 主题
- 页面中存在硬编码的颜色、间距、字体大小
- 缺乏统一的 Design Token 和组件规范

## What Changes
- **新增** 统一的 Design Token 系统（颜色、间距、圆角、字体、阴影）
- **新增** 统一的文本样式定义
- **新增** 基础 UI 组件库（按钮、卡片、输入框等）
- **重构** 整合现有主题文件，删除重复定义
- **重构** 统一使用 Cupertino 风格作为主要 UI 风格
- **重构** 主色调统一为绿色系（户外徒步主题）

## Impact
- Affected specs: 新增 `design-system` capability
- Affected code:
  - `lib/theme/` - 重构主题文件
  - `lib/app.dart` - 更新主题配置
  - `lib/ui/` - 逐步更新页面使用 Design Token

## 设计决策

### 设计方案：专业运动风格 (方案 B)

**定位**：强调专业、数据、运动追踪

**参考品牌**：Strava、AllTrails、Apple Health

### UI 框架
- **主风格**: Cupertino (iOS 风格)
- **特点**: 简洁、优雅、iOS 原生体验

### 配色方案：天空蓝调
- **主色**: `#2196F3` 天空蓝 - 清新、信任、科技
- **主色浅**: `#64B5F6`
- **主色深**: `#1976D2`
- **辅助色**: `#4CAF50` 绿色 - 成功、确认
- **强调色**: `#FF9800` 橙色 - 警告、重点
- **错误色**: `#F44336` 红色

### 界面风格
- **布局**: 列表式 + 数据卡片
- **背景**: 纯白或极浅灰 `#FAFAFA`
- **卡片**: 边框分隔，数据图表突出
- **信息密度**: 高效紧凑

### 组件风格：方正现代
- **圆角**: 小圆角 8px（按钮、卡片）
- **按钮**: 蓝色矩形，专业感
- **图标**: 实心图标，辨识度高
- **字体**: 清晰易读，数据展示优先

### 深色模式
- 第一阶段：仅支持浅色模式
- 后续可扩展深色模式支持
