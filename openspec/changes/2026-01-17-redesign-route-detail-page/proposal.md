# Route Detail Page Redesign - Proposal

**Author**: Design Team  
**Date**: 2026-01-17  
**Status**: Final

## Problem Statement

当前的路由详情页面设计存在以下问题：

1. **交互方式老套** - 使用 Tab 栏进行分类切换，不符合现代运动应用的设计趋势
2. **信息优先级不清** - 所有信息权重相同，用户容易迷失于细节，难以快速判断路线可行性
3. **地图利用率低** - 地图与下方内容分离，无法形成有效的联动体验
4. **页面过长** - 信息线性排列导致页面很长，用户需要频繁滚动

## Solution Overview

重设计路由详情页，采用**悬浮地图 + 三层优先级信息架构**的现代布局方案：

### 核心设计特点

1. **悬浮地图头图**
   - 地图固定在页面顶部，用户滚动时地图保持可见
   - 地图与下方信息联动：点击每日行程、路线分段、户外资源时，地图显示对应轨迹或位置
   - 支持 2D/3D 切换和其他地图操作

2. **三层优先级信息架构** ⭐ 核心优化
   
   **第一优先级（必须展开）** - "我想走这条路吗"
   - 概览：难度、距离、海拔、时间
   - 每日行程 ⭐ 主角：时间轴式，了解日程节奏和住宿
   
   **第二优先级（按需展开）** - "我能走吗"
   - 路线分段 ⭐ 辅助：子段难度分布，与每日行程互补
   - 户外资源（合并）：水源、营地、补给点
   
   **第三优先级（下沉）** - "我如何了解更多"
   - 装备建议、用户评论、相关路线

3. **优雅的可折叠交互**
   - 替代传统 Tab 栏
   - 平滑的 300ms 展开/折叠动画
   - 清晰的视觉反馈（箭头旋转、背景变化）

4. **地图-信息联动**
   - 点击每日行程某一天 → 地图显示该天轨迹
   - 点击路线分段某一段 → 地图高亮该段轨迹
   - 点击户外资源某位置 → 地图标记该位置
   - 单向交互（仅信息→地图），高效简洁

## Design Details

### 页面布局结构

```
┌─────────────────────────────────┐
│   导航栏（返回、菜单操作）         │  <- Fixed (44dp)
├─────────────────────────────────┤
│                                 │
│        地图区域（悬浮）          │  <- Semi-floating
│    （高度: 350dp, 可展开）      │      (350dp → 600dp)
│                                 │
├─────────────────────────────────┤
│   路线标题 + 关键指标            │  <- Sticky (100dp)
├─────────────────────────────────┤
│                                 │
│  P0 - 概览 [∨]                  │  <- Expanded
│  每日行程时间轴（可点击展开）     │  <- Expanded (200-250dp)
│                                 │
│  P1 - 路线分段简轴 [>]          │  <- Collapsed
│       可点击展开详情             │
│                                 │
│  P1 - 户外资源 [>]              │  <- Collapsed
│       水源+营地+补给（合并）     │
│                                 │
│  P2 - 装备建议 [>]              │  <- Collapsed
│                                 │
│  P3 - 用户评论 [>]              │  <- Collapsed
│       相关路线 [>]              │
│                                 │
├─────────────────────────────────┤
│        底部操作按钮              │  <- Fixed (60dp)
└─────────────────────────────────┘

估算总高度：~2000-2300dp（约 2.5-3 屏）
相比全展开节省 ~70% 的滚动距离
```

### 关键改进点

#### 每日行程设计
- **时间轴格式**：使用数字标记（1️⃣ 2️⃣ 3️⃣）+ 一行简洁描述
- **点击展开**：展示详细信息（上升、下降、时间、住宿）
- **地图联动**：点击某一天 → 地图显示该天轨迹

#### 路线分段设计
- **默认折叠为简轴**：所有分段显示在一行（月字条格式）
- **可点击展开**：展开某段显示详细信息（距离、海拔、路况等）
- **地图联动**：点击某段 → 地图高亮该段轨迹

#### 户外资源合并
- 将水源、营地、补给点合并为一个"户外资源"卡片
- 内部可分标签页或分类显示
- 减少卡片数量，信息更聚焦

## Product Rationale

**为什么每日行程是主角？**
- 用户的第一个问题是"这条路要花几天？每天多远？"
- 每日行程包含住宿信息，这对徒步规划至关重要
- 按"天"规划更符合用户的心智模型

**为什么路线分段是辅助？**
- 用户在了解了日程后，想知道"有没有特别难的段？"
- 路线分段补充日程视图，提供细粒度的难度信息
- 两者互补而非替代

**为什么合并户外资源？**
- 水源、营地、补给都是"户外生存要素"
- 合并可减少卡片数量，降低认知负荷
- 内部可分类展示，不失信息完整性
