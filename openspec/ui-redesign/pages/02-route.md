# 路线模块（Route）

---

## 2.1 路线发现页（RouteDiscoveryScreen）

**文件**：`lib/ui/page/route/route_discovery_screen.dart`

### 页面结构

导航栏：标题"路线"，无操作按钮。  
内容：CustomScrollView，支持弹性滚动。

### 地图视图（RouteMapView）
- 顶部可展开/收起的地图区域
- 收起高度：约 120dp；展开高度：约 300dp
- 切换有高度动画（300ms easeInOut）
- 右下角展开/收起切换按钮

### 筛选栏（RouteFilterSection）
- 横向滚动的筛选标签
- 选项：全部 / 热门 / 当季 / 简单 / 中等 / 困难
- 激活态：填充蓝色背景；未激活：边框样式

### 热门路线区块
- 区块标题"热门路线" + 副标题 + "查看全部"
- 横向滚动卡片（RouteCard）
- 卡片内容：封面图、路线名、位置、距离+海拔指标、难度徽章

### 当季路线区块
- 同热门路线，数据来源不同

### 全部路线区块
- 竖向列表（RouteListCard），最多显示 6 条
- 卡片内容：左侧缩略图（80×80）+ 右侧路线名/位置/指标行/难度徽章
- 超出 6 条时显示"查看更多"蓝色按钮

### 状态处理
- 各区块独立加载，互不影响
- 加载中：CupertinoActivityIndicator
- 加载失败：错误提示 + 重试
- 空数据：空状态提示

## 2.2 路线详情页（RouteDetailScreen）

**文件**：`lib/ui/page/route/detail/route_detail_screen.dart`

### 布局：地图全屏 + 悬浮导航栏 + 底部抽屉

**地图层（全屏底层）**
- 全屏地图，显示路线轨迹折线
- 轨迹数据优先级：API 轨迹点 > KML URL > 本地 assets/maps/wutai.kml

**悬浮导航栏（顶部）**
- 返回按钮（左）
- 路线名称（中，可选显示）
- 收藏按钮（右，切换状态，收藏后跳转我的收藏页）
- 分享按钮（右）

**底部上滑抽屉（RouteInfoSheetWidget）**
- 默认半展开（约屏幕 50%）
- 可上滑至全屏，可下滑隐藏
- 隐藏后底部显示触发区，上划重新打开
- 顶部有拖拽把手

**抽屉内容（滚动）：**

| 区块 | 内容 |
|---|---|
| 路线统计卡片 | 总距离 / 总爬升 / 总天数 / 评分（4格横排） |
| 每日行程 | 可展开，每天：日期、起终点、距离、关键节点 |
| 分段信息 | 路线各段详情（距离、路面类型、难度） |
| 水源点 | 列表，带水滴图标和位置描述 |
| 营地 | 列表，带帐篷图标 |
| 补给点 | 列表，带商店图标 |
| 季节装备建议 | 按季节推荐装备 |
| 图片画廊 | 横向滚动图片条 |
| 搭车联系人 | 联系方式列表 |
| 相关路线 | 横向滚动路线卡片 |
| 相关行程 | 横向滚动行程卡片 |

**底部操作栏（抽屉内固定）**
- "开始规划行程"主按钮（全宽）→ 跳转行程详情页

## 2.3 我的收藏路线页（MyFavoriteRoutesScreen）

**文件**：`lib/ui/page/route/my_favorite_routes_screen.dart`

- 导航栏：标题"我的收藏"
- 竖向路线列表（RouteListCard 样式）
- 每条路线右侧有"取消收藏"操作
- 空状态：提示"暂无收藏路线"

## 2.4 路线搜索页（RouteSearchPage）

**文件**：`lib/ui/page/search/route_search_page.dart`

**入口**：底部导航栏中间 FAB 按钮

### 页面结构

| 区域 | 内容 |
|---|---|
| 搜索框 | 自动聚焦，placeholder "搜索路线、地点..." |
| 热门搜索 | 标签云：北京周边 / 徒步路线 / 登山 / 露营 / 自驾游 / 亲子游 / 周末游 |
| 搜索历史 | 历史关键词列表，支持清除 |
| 搜索结果 | 路线卡片列表（有关键词时显示） |

### 状态
- 搜索中：loading 指示器
- 无结果：空状态提示
- 搜索失败：错误弹窗
