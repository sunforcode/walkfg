# 个人中心（ProfileScreen）

**文件**：`lib/ui/page/profile/profile_screen.dart`

---

## 导航栏
- 标题"我的"
- 右侧：设置图标按钮

---

## 未登录状态

- 提示文字"登录后查看完整功能"
- "登录"主按钮 → 跳转登录页
- "注册"次按钮 → 跳转注册页

---

## 已登录状态

### 用户信息卡片
| 元素 | 说明 |
|---|---|
| 头像 | 圆形，72dp，带蓝色边框 |
| 昵称 | 加粗，18sp |
| 个人简介 | 次要文字，14sp |
| 关注 / 粉丝 | 横排数字 + 标签 |

### 统计数据卡片（StatsCard）
3 个统计项横排：
- 已完成路线数（点击 → 已完成路线页）
- 装备清单数（点击 → 装备主页）
- 收藏路线数（点击 → 我的收藏页）
- 右上角刷新按钮

### 功能入口列表（iOS 分组样式）
| 入口 | 图标 | 跳转 |
|---|---|---|
| 我的行程规划 | calendar | MyTripPlansScreen |
| 已完成路线 | checkmark.circle | （待实现） |
| 我的装备库 | bag | EquipmentInventoryScreen |
| 收藏的路线 | heart | MyFavoriteRoutesScreen |

### 设置列表（iOS 分组样式）
| 设置项 | 说明 |
|---|---|
| 通知设置 | 推送通知开关 |
| 隐私设置 | 行程可见性等 |
| 单位设置 | 公里 / 英里切换 |
| 语言 | 中文 / English |
| 关于 | 版本号、开源协议等 |
| 退出登录 | 红色文字，点击弹出确认对话框 |

### 退出登录确认弹窗
- 标题"退出登录"
- 内容"确定要退出登录吗？"
- 取消 / 退出（红色，破坏性操作）
