# 首页（HomeScreen）

**文件**：`lib/ui/page/home/home_screen.dart`

---

## 页面结构

导航栏：标题"首页"，无操作按钮。  
内容：可垂直滚动，4 个区块从上到下排列。

---

## 区块 1：天气 & 欢迎卡片（WelcomeWeatherCard）

**数据来源**：GPS 定位 → 天气 API；无权限时降级到杭州默认位置。

| 元素 | 说明 |
|---|---|
| 问候语 | "早上好，{用户昵称}" |
| 位置 | 当前城市名 |
| 温度 | 当前温度（℃） |
| 天气状况 | 晴/多云/雨等 |
| 风速 & 湿度 | 次要信息行 |
| 卡片背景 | 天气渐变色（见设计系统） |
| 海拔按钮 | 右上角，点击 GPS 获取当前海拔，显示结果 |
| 刷新 | 支持手动刷新天气数据 |

---

## 区块 2：我的行程（PlannedTripsSection）

- 区块标题 + "查看全部"链接
- 横向滚动卡片列表
- 卡片内容：行程名、日期范围、关联路线名、参与人数图标
- 卡片背景：行程颜色调色板（绿色系渐变，循环使用）
- 点击卡片 → 进入行程详情页

---

## 区块 3：推荐路线（RecommendedRoutesSection）

- 区块标题 + "查看全部"链接
- 横向滚动卡片列表
- 卡片内容：封面图、路线名、位置标签、难度徽章、距离、爬升
- 点击卡片 → 进入路线详情页

---

## 区块 4：徒步攻略（HikingGuidesSection）

- 区块标题 + "查看全部"链接
- 横向滚动卡片列表（最多 4 条）
- 卡片内容：封面图、攻略标题
- 点击卡片 → 进入攻略详情页

---

## 状态处理

| 状态 | 表现 |
|---|---|
| 加载中 | 全页 CupertinoActivityIndicator |
| 加载失败 | 错误图标 + 错误信息 + "重试"按钮 |
| 加载成功 | 正常展示 |
| 下拉刷新 | 重新并行加载全部 4 个数据源 |

---

## 数据加载

4 个数据源**并行**加载（`Future.wait`）：
1. 用户信息 + 天气
2. 规划行程列表
3. 推荐路线列表
4. 徒步攻略列表（limit: 4）
