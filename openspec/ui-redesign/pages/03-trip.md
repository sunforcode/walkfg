# 行程模块（Trip）

---

## 3.1 行程详情页（TripDetailScreen）

**文件**：`lib/ui/page/trip/trip_detail_screen.dart`

### 两种入口

| 入口 | 说明 |
|---|---|
| 从已有行程进入 | 传入 `tripModel`，展示完整行程数据 |
| 从路线详情页进入 | 传入 `routeId`，以路线数据构造临时行程 |

### 导航栏
- 标题随行程状态变化：规划中→"行程规划" / 已确认→"行程详情" / 进行中→"进行中的行程" / 已完成→"行程记录"
- 右侧：编辑按钮（铅笔图标，仅自己的行程且状态为规划中/已确认时显示）

### 地图头部（TripMapHeaderWidget）
- 顶部地图展示行程轨迹

### 内容区块（滚动，各区块可折叠）

| 区块 | 内容 |
|---|---|
| 行程概览 | 名称、日期范围、状态徽章、参与人数、起终点 |
| 每日行程 | 按天展示，每天：日期、路段、关键活动时间线 |
| 参与者 | 头像列表 + 姓名 + 角色（组织者/参与者） |
| 装备清单 | 关联清单摘要，总重量 |
| 预算 | 总预算 + 分类明细（交通/餐食/住宿/其他） |
| 餐食 & 饮水 | 饮食计划摘要 |
| 交通 & 住宿 | 交通方式图标 + 住宿安排 |
| 天气 & 安全 | 3日天气预报迷你卡片 + 安全提示 |

### 操作
- 编辑按钮 → 跳转行程编辑页，编辑完成后刷新
- 收藏按钮（他人行程时显示）→ Toast 提示"已收藏"
- 只读模式：查看他人行程时，隐藏编辑入口

## 3.2 行程编辑页（TripEditScreen）

**文件**：`lib/ui/page/trip/trip_edit_screen.dart`

### 页面结构
- 导航栏：标题"编辑行程"，右侧"保存"按钮
- 内容：各信息区块可折叠展开编辑（TripCollapsibleSection）

### 可编辑区块
- 基本信息：名称、日期、状态
- 每日行程：添加/编辑每天安排
- 参与者：添加/移除参与者
- 装备清单：关联/更换装备清单
- 预算：填写各分类费用
- 餐食 & 饮水：编辑饮食计划
- 交通 & 住宿：填写交通和住宿信息
- 天气 & 安全：添加安全提示

### 交互
- 检测未保存更改（`_hasUnsavedChanges`）
- 离开时若有未保存更改，弹出确认对话框
- 保存成功后返回详情页并触发刷新（返回 `true`）

## 3.3 我的行程规划页（MyTripPlansScreen）

**文件**：`lib/ui/page/trip/my_trip_plans_screen.dart`

### 页面结构
- 导航栏：标题"我的行程规划"
- 行程列表（竖向）

### 行程卡片内容
- 行程名称
- 日期范围
- 关联路线名
- 状态徽章（规划中/已确认/进行中/已完成/已取消）
- 参与人数

### 状态分类
规划中 / 已确认 / 进行中 / 已完成 / 已取消

### 交互
- 点击卡片 → 进入行程详情页
