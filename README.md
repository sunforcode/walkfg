# Walk - 徒步旅行助手

Walk是一款专为徒步爱好者设计的移动应用，帮助用户规划、记录和分享徒步旅行体验。

## 行程规划功能设计文档

### 功能概述

行程规划功能允许用户基于已有的徒步路线创建个性化的行程计划，包括日程安排、交通接驳、装备清单等，帮助用户更好地准备和执行徒步旅行。

### 用户流程

1. **浏览路线**：用户可以浏览推荐路线或搜索特定路线
2. **选择路线**：用户选择一条路线作为行程规划的基础
3. **基本信息设置**：设置出发日期、参与人数、出发城市等基本信息
4. **行程定制**：根据需要调整每日行程、添加途经点、选择营地等
5. **交通规划**：添加前往起点和离开终点的交通方案
6. **装备准备**：查看和管理装备清单，标记已准备的物品
7. **轨迹下载**：下载路线GPX文件或分享给其他设备
8. **保存计划**：保存行程计划，可随时查看和修改

### 数据模型

#### 行程计划模型 (TripPlanModel)
- 基本信息：ID、用户ID、路线ID、路线名称、出发日期、参与人数、出发城市
- 行程安排：每日行程列表
- 交通方案：前往起点和离开终点的交通方案
- 装备清单：需要准备的装备列表
- 状态信息：最后编辑时间、计划状态(草稿、已确认、进行中、已完成、已取消)

#### 每日行程模型 (DailyItinerary)
- 基本信息：天数、起点、终点、距离、累计上升、累计下降
- 途经点：当天需要经过的途经点列表
- 营地信息：推荐营地和备选营地
- 时间估计：预计用时

#### 途经点模型 (WaypointModel)
- 基本信息：ID、名称、描述、位置(经纬度)、海拔
- 类型信息：类型(起点、终点、休息点、观景点、水源点、营地、其他)
- 时间信息：预计到达时间

#### 营地模型 (CampSiteModel)
- 基本信息：ID、名称、描述、位置(经纬度)、海拔
- 设施信息：容量、设施列表、水源距离、特点

#### 交通方案模型 (TransportationPlanModel)
- 基本信息：ID、名称、类型(公共交通、包车、自驾、其他)
- 行程信息：出发地、目的地、出发时间、到达时间
- 其他信息：费用、描述

#### 装备项模型 (EquipmentItemModel)
- 基本信息：ID、名称、类别、是否必备、描述
- 状态信息：是否已准备

### 界面组件

#### 行程规划首页 (TripPlanningScreen)
- 当季热门路线展示
- 按地区、难度、时长等分类浏览路线
- 搜索功能

#### 路线选择页面 (TripRouteSelectionScreen)
- 路线列表展示
- 筛选功能(难度、时长、季节等)
- 路线卡片(包含基本信息和规划按钮)

#### 行程规划详情页面 (TripPlanningDetailScreen)
- 基本信息设置区域
- 标签页导航(行程概览、每日行程、交通接驳、营地信息、装备清单、轨迹下载)
- 保存按钮

##### 行程概览标签页
- 路线概览卡片(图片、描述、基本数据)
- 行程总览(出发日期、人数、天数等)
- 天气预报
- 注意事项

##### 每日行程标签页
- 每日行程卡片列表
- 行程编辑功能
- 途经点管理
- 营地选择

##### 交通接驳标签页
- 前往起点交通方案
- 离开终点交通方案
- 交通方案添加和编辑

##### 装备清单标签页
- 装备准备进度统计
- 按类别分组的装备列表
- 装备项添加、编辑和标记

##### 轨迹下载标签页
- 轨迹预览地图
- 轨迹信息展示
- 下载选项(GPX、KML等格式)
- 导航应用打开选项

#### 我的行程规划页面 (MyTripPlansScreen)
- 进行中的规划列表
- 历史规划列表
- 行程状态标识
